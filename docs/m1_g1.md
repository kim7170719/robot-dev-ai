# Gate G1 verification

Do not claim G1 until the table in `docs/progress.md` is PASS. Not Cosmos. Not Windows ROS.

## Clean terminal

```bash
source /opt/ros/jazzy/setup.bash
cd ~/dev/robot-dev-ai/ros_ws
colcon build --packages-select m1_baseline
source install/setup.bash
```

## Launch four nodes

```bash
ros2 launch m1_baseline m1_graph.launch.py
```

Starts `m1_talker`, `m1_listener`, `m1_adder`, `m1_fibonacci`.

## CLI (second terminal, same source)

```bash
source /opt/ros/jazzy/setup.bash
source ~/dev/robot-dev-ai/ros_ws/install/setup.bash
ros2 node list
ros2 topic list
ros2 topic echo /chatter --once
ros2 service list
ros2 service call /add_two_ints example_interfaces/srv/AddTwoInts '{a: 2, b: 3}'
ros2 action list
ros2 action send_goal --feedback /fibonacci example_interfaces/action/Fibonacci '{order: 3}'
```

Expect `sum: 5` and Fibonacci result `[0, 1, 1, 2]`.

Other local ROS graphs (for example a ZED driver) may also appear in `ros2 node list` on this machine. G1 only requires the four `m1_*` nodes from this launch.
